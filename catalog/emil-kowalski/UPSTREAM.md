## Aplicación prioritaria en Pillaki

| Skill | Aplicación |
| --- | --- |
| `improve-animations` | Auditar animaciones de la web completa antes de tocar componentes. |
| `review-animations` | Revisar transiciones existentes, entrada y salida de elementos. |
| `animation-performance` | Reducir animaciones pesadas, saltos y bloqueos en móviles. |
| `find-animation-opportunities` | Proponer movimiento únicamente cuando mejore la comprensión. |
| `remove-animations` | Eliminar efectos innecesarios o distractores. |
| `mobile-native` | Revisar controles táctiles, viewport, inputs y respuesta móvil. |
| `break-ui` | Probar textos largos, estados vacíos y contenido extremo. |
| `animate` | Crear una animación nueva solo tras aprobar un objetivo concreto. |

## Instalación oficial en entorno cloud autorizado

Desde el **directorio de un checkout de prueba**, nunca desde el proyecto en producción:

```bash
npx skills@latest add emilkowalski/skills
```

Seleccionar las skills necesarias y el proveedor compatible que indique el instalador. Revisar su contenido y licencias antes de ejecutar scripts o aceptar permisos. No instalar globalmente ni en el equipo personal sin autorización expresa.

## Restricciones

- No sustituir la identidad visual, logotipos, paleta o tipografía aprobados.
- Respetar `prefers-reduced-motion` y evitar animaciones que oculten información esencial.
- Priorizar transformaciones y opacidad, probar rendimiento móvil real y no bloquear formularios.
- Mantener los trabajos de Pillaki aislados de Gráfica SF, Cotiza GSF e INGELMAR.
- Generar propuestas en ramas independientes y revisión humana antes de publicar.
