## Para qué la usamos

Biblioteca orientada a revisión y diseño web integral, incluyendo:

- UI y UX;
- tipografía web;
- teoría del color;
- accesibilidad;
- responsive design;
- navegación;
- branding;
- landing pages;
- auditoría de sitios;
- patrones de componentes y dirección visual.

## Skill especialmente útil

`webdesign-review` coordina una revisión multidisciplinaria del sitio y resulta especialmente útil para auditorías como la futura modernización de Induscan.
