# Material Web — referencia para Pillaki

Fuente oficial: https://github.com/material-components/material-web
Paquete: `@material/web`

## Qué aporta

Biblioteca de Web Components basada en Material 3 para construir interfaces accesibles y consistentes: botones, campos de texto, checkbox, radio, select, diálogos, tabs, chips, listas, menús, switches y progreso.

## Uso recomendado en Pillaki

- Formularios de diagnóstico y contacto.
- Cotizadores y flujos comerciales.
- Paneles privados y dashboards.
- Landings con controles complejos.
- Componentes reutilizables internos.

## Estado del proyecto

El repositorio oficial indica que Material Web está en **maintenance mode pending new maintainers**. Por eso Pillaki debe usarlo de forma selectiva, priorizando APIs estables y evitando depender de features experimentales.
