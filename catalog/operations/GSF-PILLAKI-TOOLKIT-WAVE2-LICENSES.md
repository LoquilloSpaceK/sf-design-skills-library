# Wave 2 — Fuentes y licencias

Referencias verificadas al incorporar el Toolkit Operativo Wave 2.

## Grafana k6
- Fuente: `grafana/k6`
- Licencia declarada: AGPL-3.0.
- Uso previsto: herramienta externa de pruebas de carga; no copiar ni redistribuir su código dentro de proyectos de clientes sin revisar obligaciones AGPL.

## Mailpit
- Fuente: `axllent/mailpit`
- Licencia: MIT.
- Copyright indicado: Ralph Slooten, 2022-Now().
- Uso previsto: servidor SMTP de desarrollo/staging para capturar y probar emails.

## Sharp
- Fuente: `lovell/sharp`
- Licencia: Apache-2.0.
- Copyright indicado por upstream: Lovell Fuller y otros.
- Uso previsto: procesamiento y optimización de imágenes en proyectos Node.js.

## Lychee
- Fuente: `lycheeverse/lychee`
- El upstream conserva textos de licencia MIT y Apache-2.0.
- Uso previsto: detección de enlaces rotos en sitios, HTML, Markdown y CI.

## Umami
- Fuente: `umami-software/umami`
- Licencia: MIT.
- Copyright indicado: Umami Software, Inc., 2022.
- Uso previsto: analítica privacy-first opcional, self-hosted o cloud según proyecto.

## Dependabot Core
- Fuente: `dependabot/dependabot-core`
- Licencia: MIT.
- Copyright indicado: GitHub, Inc.
- Uso previsto: referencia técnica; en repositorios GitHub se prefiere habilitar el servicio nativo mediante `dependabot.yml` en lugar de autoalojar el core.

## OpenTelemetry JS
- Fuente: `open-telemetry/opentelemetry-js`
- Licencia: Apache-2.0.
- Uso previsto: instrumentación vendor-neutral de trazas, métricas y logs en aplicaciones JavaScript/Node cuando la complejidad lo justifique.

## Regla

Las licencias y condiciones deben volver a verificarse antes de incorporar o redistribuir código de terceros en un proyecto comercial. Este documento registra el estado revisado al crear la Wave 2 y no sustituye los textos de licencia oficiales de cada upstream.
