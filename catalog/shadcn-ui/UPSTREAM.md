## Qué es

shadcn/ui es una colección de componentes de interfaz abiertos y personalizables que se incorporan al código del propio proyecto. Su filosofía es usar los componentes como punto de partida para construir una biblioteca propia, en vez de depender de una caja negra cerrada.

## Por qué interesa a Pillaki

Es especialmente útil para construir interfaces de clientes con una base visual consistente, moderna y accesible, manteniendo control total sobre el código y el branding final.

Áreas prioritarias para reutilización:
- formularios y validaciones;
- dashboards y paneles privados;
- tablas, filtros y navegación;
- modales, drawers y menús;
- botones, inputs, selects, tabs, tooltips y alerts;
- layouts de administración;
- landing pages y portales de clientes;
- componentes responsive reutilizables.

## Política de uso

1. No copiar una demo completa como producto final sin adaptación.
2. Reutilizar componentes seleccionados y adaptarlos al sistema visual del cliente.
3. Mantener el aviso de licencia MIT cuando se copie una porción sustancial del software.
4. Revisar dependencias y requisitos del componente antes de incorporarlo a producción.
5. Priorizar accesibilidad, rendimiento y simplicidad sobre efectos innecesarios.
6. No modificar automáticamente `pillaki.cl` ni otros repositorios productivos al consultar esta biblioteca.
